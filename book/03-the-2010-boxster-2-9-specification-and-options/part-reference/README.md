# Factory references for the specification and option map

Checked 10 November 2026. This chapter establishes the **2010 European/UK Boxster 2.9**, with standard six-speed manual and optional seven-speed PDK. The pages below support model/assembly identification and the chapter's broad option map. Detailed component chapters own the individual mechanisms.
