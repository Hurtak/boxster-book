# Halogen front-lighting photograph

Verified **14 November 2026** for the standard halogen arrangement on the 2010 European/UK Boxster2.9 reference.

- **Original photographer/publisher:** Cameron Sports Cars Ltd, [listing U1674](https://www.cameronsportscars.com/vehicle-details/used-porsche-boxster-987-2-9-gen-2-manual-for-sale-in-chippenham-south-gloucestershire-u1674/), advertised as a2010 Boxster987.2 2.9 six-speed manual. Registration/supply dates are not an independently verified model-year build record.
- **Original image:** [IMG_32632-large.jpg](https://img.cdn.dragon2000.net/C1353/U1674/IMG_32632-large.jpg), copied byte-for-byte to `../../images/halogen-front-cameron-original.jpg`. No recolouring, mirroring, retouching or resampling; original watermarks retained in the file. Native photograph:1280×849.
- **Identification:** visible rectangular fog-lamp reflectors in the lower modules, upper halogen arrangement and absence of headlamp-cleaning nozzles are consistent with the standard arrangement. The lower hardware was checked against Porsche's detailed UK01/10 printed64–65 lighting description and PET905-000 / PDF552. Projector shape or missing washers alone is not proof of equipment. The dealer's generic LED-daytime-running-light line is not adopted as proof of P75 or used to override the factory distinction between standard LED position lights and P75 LED DRLs.
- **Existing P75 photograph:** unchanged Porsche AG `../../images/porsche-front-lights.jpg`,381×282, from *The Boxster*, UK01/10 printed65 / PDF30. This is a documentary image of the optional setup; no unbadged2.9/S identity inferred.
- **React composition:** standard photo viewport `x212,y285,width855,height444`; P75 viewport `x53,y110,width285,height148`. Both have an aspect ratio of285:148 and display both main and lower lights. Cropping is a CSS viewport into the original asset. No altered or annotated derivative bitmap is created. Native notes identify the different functions.
- **Limits:** photographs have different lighting and camera elevation. They compare visible equipment, not photometry, brightness, beam pattern, exact dimensions, colour temperature or every fitted option. Original files remain available for source checking. The independent PET construction figure remains in the chapter.
