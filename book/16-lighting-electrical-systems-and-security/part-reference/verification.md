## Checks and remaining limits

Local verification covers model module syntax/import, eight unique groups with finite geometry, all connection endpoints/kinds, four SVG XML files, MDX syntax, chapter asset/source links and unchanged footnote-reference sequence/count, heading text and diagram IDs. Integrated rendering remains parent-owned; `electrical-explorer` is the only poster needing regeneration from this pass. No standalone SVG geometry changed.

Unresolved by this evidence: exact harness routes, distributor mounting coordinates, controller brackets represented symbolically, internal starter/alternator supplier construction, photometry, cornering activation/control calibration, universal DRL coding, later ordinary-2.9 annual equipment continuity and current replacement-part availability. These are not silently converted into facts.
